Implement the Service Order AI API.

Endpoint:

GET /api/ai/service-orders/{order_number}

Data source:

AIServiceOrderRepository

Authorization:

Customer:
- Can only access own service orders.

Staff:
- Can access assigned/authorized orders.

Manager:
- Can access authorized organizational scope.

Response:

- order_number
- customer
- service_type
- laboratory
- order_status
- inspection_status
- sla_status

Security:

- No raw SQL from request.
- No direct database access from Langflow.
- Validate order_number.
- Enforce authorization server-side.
- Prevent IDOR.
- Do not expose unauthorized customer information.
